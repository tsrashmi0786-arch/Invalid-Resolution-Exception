# Print Order - Abstract Class

## Aim

To create a Java program using an abstract class `PrintOrder` and a
subclass `PosterPrint` to demonstrate abstraction and method overriding.

## Description

This program demonstrates abstraction in Java using a printing-order
scenario. `PrintOrder` is an abstract class that contains the abstract
method `processPrint()`. The `PosterPrint` class extends `PrintOrder`
and provides an implementation for the `processPrint()` method.

## Concepts Used

- Abstract Classes
- Abstract Methods
- Inheritance
- Method Overriding
- Objects and Classes

## Problem Statement

Create an abstract class named `PrintOrder` with an abstract method
`processPrint()`. Extend the class using `PosterPrint` and implement
the `processPrint()` method to process a poster print order.
