# Invalid Resolution Exception

## Aim

To create a Java program using a custom `InvalidResolutionException` to handle an invalid photo resolution.

## Description

This program demonstrates custom exception handling in Java. The program accepts the photo resolution from the user and checks whether the resolution is zero. If the resolution is zero, the custom `InvalidResolutionException` is thrown and handled using a `try-catch` block.

## Concepts Used

- Exception Handling
- Custom Exception
- `try-catch`
- `throw` keyword
- User Input using `Scanner`

## Problem Statement

Create a custom exception named `InvalidResolutionException` and throw it when the photo resolution entered by the user is zero.
