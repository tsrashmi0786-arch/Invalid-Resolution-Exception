# Photography Studio

## Aim

To create a Java program using a `Photo` class and an `EditedPhoto`
subclass to demonstrate inheritance, constructors, and method overriding.

## Description

This program represents a photography studio. The `Photo` class stores
the title and resolution of a photograph. The `EditedPhoto` class
inherits these properties and adds information about the filter applied
to the photograph.

The program demonstrates how inheritance and method overriding are used
in Java.

## Concepts Used

- Classes and Objects
- Constructors
- Inheritance
- Method Overriding
- `super()` keyword

## Problem Statement

Create a `Photo` class with `title` and `resolutionMP` attributes.
Create a subclass `EditedPhoto` that adds a `filterApplied` attribute
and overrides the `display()` method to display all the photo details.
